2. Music Playlist Manager

A menu-driven music playlist management system built using a Doubly Linked List.

Features:

Insert songs into the playlist
Display all songs
Search for a song
Count total songs
Delete songs from the playlist
Play next song
Play previous song
Shuffle playlist
Save playlist to a file
Load playlist from a file

Concepts Used:

Doubly Linked List
Dynamic Memory Allocation
Structures
Functions
File Handling
Menu-Driven Programming

How to Compile and Run

Compile any project using GCC:

gcc filename.c -o output

Example:

gcc music_playlist_manager.c -o playlist_manager

Run the executable:

./playlist_manager
