# 📂 Mini Projects

Welcome to the **Mini Projects** directory! This folder contains complete, hands-on mini-applications built using C programming to demonstrate real-world logic, file handling, and structure management.

---

## 🛠️ Projects List

### 1. Student Record System (`StudentRecord.c`)
A console-based application designed to manage student data efficiently. It allows users to perform standard CRUD (Create, Read, Update, Delete) operations on student files.

* **Key Features:**
    * Add new student records (Name, Roll Number, Marks, etc.).
    * View and list all stored student records.
    * Search for a specific student by Roll Number.
    * Modify or update existing student information.
    * Delete a record from the database.
* **Concepts Used:** Structures, Loops, and Functions.
